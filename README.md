# Sistema de Login

Sistema de login clásico en Java con Spring Boot sin usar JWT.

## Funciones
* Registro e inicio de sesión de usuarios.
* Validación de credenciales en base de datos.
* Control de sesión tradicional del servidor.

## Tecnologías
* Java
* Spring Boot
* MySQL

## Ejecución
1. Configura el archivo application.properties.
2. Ejecuta la aplicación.
